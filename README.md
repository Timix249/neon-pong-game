# Neon Arcade

Eine Spielhalle für den Browser mit eigenem Versionsarchiv.

- [Versionsübersicht](https://timix249.github.io/neon-pong-game/)
- [Version 1 — Neon Pong](https://timix249.github.io/neon-pong-game/v1/)
- [Version 2 — Neon Arcade](https://timix249.github.io/neon-pong-game/v2/) mit Neon Pong, Neon Drift und Orbit Siege

Die Hauptseite verlinkt alle veröffentlichten Versionen. Jede Version liegt in einem eigenen Verzeichnis. Zum lokalen Testen das Repository mit einem statischen HTTP-Server öffnen.
